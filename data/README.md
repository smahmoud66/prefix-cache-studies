# Data, transformations and attribution

This repository includes simulation results and a numeric witness panel, not original prompts, private production logs, model weights or unrelated research data. Each entry of [upstream.json](upstream.json) pins the input URL, SHA-256 digest and scratch path for reconstruction. Public datasets retain their upstream terms.

- [Mooncake FAST ’25 traces](https://github.com/kvcache-ai/Mooncake/tree/3cca71daccf2a7afb8fe3f0295358f70e3a69fdb/FAST25-release/traces), Mooncake authors. The conversation and tool/agent streams provide length and prefix identifiers. The benchmark reconstructs prefix identities, bins and warm-ups. The ordering pilot uses a chronological window. See [source receipt](../research/commitment_20261108/inputs/receipt.json).
- [Qwen/Bailian anonymized traces](https://github.com/alibaba-edu/qwen-bailian-usagetraces-anon/tree/5f7439c51ec248a0c585f7d90a41a6f57773b912), Alibaba Qwen/Bailian trace authors, [upstream Apache 2.0 license](../research/external_tie_20261109/source/LICENSE.meta). The adapter reconstructs lineage-local 512-token paths. Original inputs are fetched at their LFS object digests; external TSVs contain derived scheduling counts and timings.
- [FreeInference data](https://huggingface.co/datasets/harvardMadsys/2026_prefixcache/tree/ba89a343a048073dda72617bb6087910da6214d0), Yiyu Liu, Minlan Yu and Juncheng Yang. Source and adapted panel: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: select the first 5,000 by arrival across the full object, preserve predecessor constraints, combine 32 original 16-token blocks into one 512-token block, infer user-namespaced prefix nodes, cap the path at 128 nodes, and replace labels with local integer IDs. [panels-freeinference.txt.gz](panels-freeinference.txt.gz) contains relative arrivals, lengths, predecessor indices and these interned node IDs. The [format](https://github.com/cacheMon/PrefixSim/blob/160d5f81724dd9ec28b10d6abb64615e6adbb332/doc/lcp_format.md) and [authors’ paper](https://arxiv.org/abs/2609.28870v3) describe the upstream dataset.
- [NVIDIA AIConfigurator](https://github.com/ai-dynamo/aiconfigurator/tree/6cd6f9686ab7de6e8fb28171d6e350ee0aa4ed39/aic-core/src/aiconfigurator_core/systems/data/h100_sxm) SGLang H100 SXM component data; [Qwen3-8B model configuration](https://huggingface.co/Qwen/Qwen3-8B/blob/b968826d9c46dd6066d109eabc6255188de91218/config.json). Frozen points and parameters describe a component cost model, not measured service TTFT.

The two `exit_cache_*.jsonl.gz` files are recorded Mooncake study outputs with request indices and computed costs. `external-timing-rows.tar.gz` holds the Qwen/Bailian comparison's per-cohort TSV rows. The upstream repositories are unaffiliated with this artifact.

The two compressed Qwen cohort ledgers contain numeric arrival and grouping data derived from the attributed Bailian release; they support independent timing readback.

The earlier commitment-study development and evaluation records are included as compressed JSON Lines. Historical narrative links point to the corresponding packaged records. The original machine-specific report path in one historical checkpoint has been replaced by its relative filename.
