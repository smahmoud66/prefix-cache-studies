# Frozen evaluators and mechanism accounting

All requested modes use the legacy current-order search, complete-exit grouping, integer sums and incumbent/lexicographic priority. Each historical pair starts anew from each immediately optimal exit with the same completed demand. The absolute interface returns (preferred representative order code, sum of missing historical blocks) for each distinct immediately optimal full exit. The common immediate contribution is available as the reported minimum times the denominator. A code packs each zero-based order index in two bits and is interpreted at the known cohort width. The decision-only interface need only select the original order and its actual full exit. The universal no-pairs and one-eligible-exit shortcuts are allowed there without scoring. Pair-common skipping across alternatives belongs to the sharing switch. In absolute mode such a constant is computed on one representative and restored to all.

| Mode | Direct certificate | Rank-key sharing within a pair | Representation used on a residual replay |
|---|---|---|---|
| FULL = R00 | Off | Off | Original complete state |
| R10 | On | Off | Original complete representative |
| R01 | Off | On | Original complete representative |
| R11 | On | On | Original complete representative |
| FOCUSED | On | On | Correlated projected identities and their absolute ranks |

FULL and R00 invoke the same path. In the frozen R11 algorithm the projected state determines which score can be reused and which can be obtained directly. The remaining classes are replayed on their original witnesses. With both shortcuts removed, materializing and discarding an unused rank key would change only measurement cost. FULL/R00 timing is counted once. R01 is a direct known-support adaptation that groups exact keys and serves as the certificate-off comparator. A focused evaluator given the joint survival consequence and permission to use its original complete witness on a residual miss can *also* coincide operationally with R11. To measure the distinct straightforward reduced-state implementation, FOCUSED propagates actual focused observations on those misses, without an obligatory conversion on any certified candidate. **Source grounding.** For any resident tracked node, its older-to-newer relations to other tracked nodes are recoverable from joint labeled ranks. Its younger outsider count equals its absolute rank minus one minus the number of tracked nodes ahead. An untouched outsider cannot become younger than an untouched tracked node during the pair. For a tracked resident outside the new path P, the simultaneous younger set is the union of its former younger set with P. Eviction occurs precisely when its new cardinality reaches capacity. A touched node's new younger set is its shallow-to-deep path predecessors. An absent untouched node remains absent. Hits for all of P are charged before this update. This is the same atomic recurrence as the manuscript and retains correlations within each candidate trajectory. The focused kernel projects the initial concrete state once per actual residual replay, advances its own adaptive selector, and discards its hypothetical output. **Analytical regimes.** Start from empty in the following reachable, single-block-root examples. (i) Let C=3 and permute the current cohort x,y,a. The two exits (a,x,y) and (a,y,x) have the same key on U={a,b,c,d}. All immediate charges were three. A historical pair serving all four members fails the capacity-only part of the certificate, but one projected class suffices for these two exits. (ii) Let C=3 and permute a,b,c. The six exits have distinct keys on U={a,b,c}, so no two merge. All six certify zero misses when the pair serves a,b,c, since every key contains all tracked identities and no outsiders. (iii) Let C=2 and permute a,b. On U={a,b,c} both keys are distinct, both fail certification, and each must be evaluated under each evaluator's prescribed rule. This last example proves absence of replay reduction by these shortcuts there. It gives no universal lower bound on any exact evaluator.

**Cost model.** For one decision let C be the retained slots, E the number of distinct immediately optimal full exits, and V the number of current partial-order nodes generated. Repeatedly applying the common O(C) transition and retaining V physical state arrays costs O(VC) space and O(VC) transition work, plus common incumbent search, bounds and full-exit deduplication (naive linear comparisons O(AEC) for A eligible orders). The physical MAX_CAP is 128 across these tests. Operations that copy or initialize a full physical state may scale with MAX_CAP at logical capacity 32. For a pair let u be the size of its exact union, g its requests, k≤4 the maximum cohort width, B its path-node occurrences. The shared established chronological history holds ≤16 groups. When needed, the rolling bit-membership map and distinct counts take linear visits over arriving/expiring path occurrences, amortized dense-vector growth/initialization and O(I) dense storage for I encountered identities. R01 stores only bit membership and omits distinct-count updates. R10/R11/FOCUSED store membership and the adjacent-pair union cardinalities. FULL retains the paths only. All modes also pay shared canonical-ID ingestion, transition scratch and input history storage.

Let R bound one concrete replay. Path processing costs O(B) and scans of retained state and k-LPM hit probes cost O(g[C+k log(C+1)]) with C-sized physical states. On nontrivial pairs FULL and R00 execute E replays, O(ER). R10 checks up to E exits, including a constant-time rejection whenever u>C. Let S be certified exits. Its historical cost is O(EC+(E−S)R), with no per-pair memo. R01 and R11 first find potentially distinguishing ranks once per decision in O(EC) time and O(C) temporary rank slots. Any common pair can be omitted in decision-only mode; absolute scoring computes one common score and broadcasts it. On a nonconstant pair let L=E−S (for R01, S=0), D≤L be distinct uncertified key classes. The key may require O(C) visits per residual candidate; linear memo lookup with equality on full rank-identity keys can cost O(LDC). R11 costs O(EC+LDC+DR) per such pair, with O(DC) additional per-pair key words and O(E) sums. R01 has the same expression with S=0 and no certificate scans. FOCUSED uses precisely the same certificate, classes, keys and lookup, replacing R with Rf. With H_j≤min(C,u) tracked residents at step j, the focused kernel pays one O(C) initial projection, O(B) inserted path nodes, O(sum_j H_j) tracked-entry visits at atomic updates and adaptive membership marking, and O(gk log(C+1)) probes. It reserves two fixed arrays of (id,rank) pairs sized to physical capacity. If D=L=E and S=0, decisions may pay full replay plus projection/lookup. Reduced replay counts do not establish an asymptotic speedup or total-time improvement.

**Timing and counting.** Common native generation includes incumbent computation, full-state deduplication and enumeration. The historical phase runs after representative construction and includes differing-rank precomputation, summation, lookup, certification, all residual replays, winner selection and producing the requested all-score vector when applicable. The native selection CPU timer contains both subphases, result materialization and local destructors. Per-command parse/setup CPU and applied-state/history-update CPU are additional disjoint intervals. The caller time includes the same JSON serialization, full state return, IPC and decode as required by the corresponding interface across all methods. Absolute output is intentionally larger and compared only to absolute output. Peak native process RSS is separate from vector capacities and stack estimates; they must not be added. Counters record direct checks and actual successes, memo attempts/hits and key words, differing-rank comparison slots and key visits, index occurrence updates, full versus focused simulated requests, and focused projection visits. Component CPU counters are diagnostic reads of CLOCK_PROCESS_CPUTIME_ID in a single process. The historical timer excludes index maintenance; complete decision timing charges it. Full-witness kernels do not explicitly advance a projected state on residual replays. R00's zero projected updates/keys are therefore genuine. The index capacity may exceed the live support; a 16-group window does not bound it in a continuous episode.
