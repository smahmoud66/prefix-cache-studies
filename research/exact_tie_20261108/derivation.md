## Historical-pair projection

Work in missing retained blocks. The parent proof applies to reachable prefix-closed states under ordinary LRU, one service stamp per request, shallow-to-deep path priority within a stamp, protected admissions, fixed capacity `C`, and capped paths with unique canonical node IDs. Write an exit `F` from highest to lowest retention priority. For a request path `P`, its cost is the number of its absent nodes **at entry**; its next state is the first `C` nodes of the concatenation of `P` and the old list with members of `P` deleted. Prefix closure makes the hit set on any candidate path an initial path segment. [Parent proof](../exit_cache_20261108/review.md)

Within one completed historical pair, let `U` be the union of the capped path nodes of all its requests, and let `u=|U|`. Compute `U` before comparing exits. For a particular exit record `(rank, node)` for each resident member of `U`, in increasing one-based MRU rank. Call this sequence `K`. An equivalent encoding keeps every gap between these nodes and the leading gap, replacing each outside identity by an indistinguishable placeholder. All trailing outsiders and vacant slots can be discarded. Equality must compare the complete key, including labels and ranks. Reuse is valid within the given pair and capacity.

**Proof.** A key gives each tracked node's initial membership and rank, including absence for a missing label. For a given next request `P ⊆ U`, the key gives the hit length and immediate miss count. After the transition, each node of `P` has its one-based position in `P` as its new rank. An old resident `x ∈ U` outside `P` at rank `r` now has prospective rank

```
|P| + r − number of nodes in P whose old rank is ≤ r.
```

It survives exactly when this rank is at most `C`. An absent tracked node outside `P` stays absent. This formula uses only the old key and the known ordered path. Hence the projected next key and cost are functions of the old key. In each cohort's even-numbered slots (zero-based) k-LPM chooses the oldest pending request. In odd-numbered slots it uses longest currently cached prefix and arrival priority. Equal keys therefore induce identical choices, pending sets, costs and successor keys step by step, including the k-LPM cycle reset for the second cohort. Computing the original continuation on one complete representative gives the exact scalar cost for its whole key class. A representative's complete terminal state need not agree with another's. Only their cost is reused, and these hypothetical states are discarded between pairs.

**A direct score from the same projection.** Let `h` be the key length. For `h>0`, let `z` equal the greatest recorded rank minus `h`. This counts initial outside-`U` entries ahead of the deepest tracked resident. For `h=0`, put `z=0`. If `u+z≤C`, return `u−h` without a rollout. For any initially surviving tracked node not yet touched, every outsider ahead of it was initially ahead of it, since the pair only touches members of `U`. There are at most `z` such outsiders and at most `u−1` other tracked nodes ahead. This bound applies to its prospective rank before each truncation, so it survives to its first touch. Once touched, a tracked node can have only other members of `U` ahead of it, even while a whole new path is prepended, so its rank stays at most `u≤C`. Thus every initially absent member misses on its first appearance and every other occurrence hits. All requests in both cohorts are eventually served, in whatever order k-LPM selects. This establishes `u−h` without assuming additive independence outside the certified case. `U=∅`, partially filled caches and duplicate requests are covered. Failure of the sufficient test calls for the exact projected-key replay. The test need not capture every pair whose cost equals `u−h`.

**Recognizing an additive constant.** Pad exits with an absent symbol up to capacity. At ranks where the eligible full exits disagree, collect every identity present there across those exits, including the identity of the first exit. If that collection is disjoint from a pair's `U`, then at every differing rank all projected entries are outsiders or absent; at every other rank the entries are identical. Hence all labeled ranks are identical for the pair. Its cost is a common constant, and no choice can change when it is omitted. If the absolute objective is requested, evaluate one representative and restore the common cost for every exit. Membership bits by chronological cohort permit this check for all pairs from the bounded ring of completed cohorts. Bits for removed cohorts must be cleared before their slots are reused. This uses the same key-equality proof, including when all exits have identical ranks or all pair paths are empty.

**Selecting an action.** Generate all current orders that attain the minimum immediate cost, retaining the original immediate incumbent and the arrival-lexicographic priority. Exact bounds can only discard an order when it cannot tie the best immediate cost, or when every possible completion has been represented. The existing cost certificate alone cannot certify a history-optimal exit. Among identical complete exits, use the eligible order preferred by incumbent/lexicographic priority. For each historical pair, score every remaining exit as above and add the integer pair cost to that exit's sum. Sharing a pair score never merges actions across other pairs. Adding the common `max(1,m) × immediate minimum` restores the reference's integer objective; with zero complete pairs the sum is empty and the incumbent wins. With only one eligible complete exit, its score is action-independent and can be omitted for decision timing if an absolute-score check separately measures it. Rank the same sums and use the same deterministic final preference. The actual post-decision state is the selected order's own full exit. Starting from the common warm state, induction on cohorts then yields the same order, full entry/exit and episode work as the reference.

With `B` path-node occurrences in a pair, `E` eligible full exits, `C` slots, `J` requests and `D` distinct keys outside the direct-score case, the pair needs `O(B)` work to gather its labels and up to `O(E C)` visits to classify the exits. It executes `D` continuations, each of `J` original transitions, rather than `E` continuations. Equality, hashing or sorting of projected tuples adds a representation-dependent cost. Storing keys for one pair at a time takes up to `O(E C)` rank/label entries plus membership scratch. Worst case `D=E` and the extra projection work can increase runtime. Costs of cache construction, retained memory, initialization and lookup belong in the benchmark.

## Counterexamples

- At capacity two, serve singleton roots `a,b` in opposite orders from empty to obtain `(a,b)` and `(b,a)`. Pair `([c],[a])` has `U={a,c}` and the same sole visible resident `a` from both exits. The first exit incurs one miss, the second two. Resident sets, tracked membership, and the compressed relative order of tracked labels all give the same weaker representation. Rank gaps distinguish them. The first exit has `z=0` and meets the direct-score test at equality. The second has `z=1`; testing only `u≤C` would incorrectly predict one miss there as well. Thus the immediate-cost certificate for current requests `[a,b]` cannot justify inspecting just one exit.
- The same exits under pair `([c,a,b],[c])` illustrate adaptive ordering. Historical k-LPM chooses `c,a,b` in the first cohort from `(a,b)` and `c,b,a` from `(b,a)`; the true two-cohort scores are each three. Replaying the first exit's fixed historical order on the second exit instead produces four misses.
- Even when a scalar-reference sequence can reproduce the final MRU tuple, it may charge the wrong atomic path cost. With `C=2`, initial `(b,a)` and a new path `[a,x]` with `x` a child of `a`, the parent rule charges one miss, then prepends `(a,x)`. If one serializes this update as scalar touches `x` then `a`, `x` evicts `a` before its touch, yielding two misses. All proofs above use path-entry hits and protected admission.

## Relationship to prior work and actual source use

Mattson, Gecsei, Slutz and Traiger's stack processing already exploits LRU rank to compute cache behavior on a fixed address trace; their LRU update near Fig. 7 gives the scalar move-to-front rank rule. Touzeau, Maïza, Monniaux and Reineke describe an exact block-focused abstraction for scalar LRU that tracks the younger addresses for each block of interest and an absent marker (§§3.2, 4.2). They use it to classify possible hits and misses over program paths. In our fixed pair, addresses outside `U` are never touched, so their individual names do not affect the younger-address update. Keeping the ranks and identities of all resident queried blocks preserves the joint observations needed to choose the next scheduled path. The derivation above and its retention bound apply these established LRU principles to atomic prefix admissions and an adaptive historical replay.
