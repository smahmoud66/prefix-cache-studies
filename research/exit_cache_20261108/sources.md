## Mechanism reasoning

Retain the default estimator. Before dispatch, index the completed chronological cohorts by 0 through n−1. Pair n−2 with n−1, n−4 with n−3, and so on, for m = min(8, floor(n/2)) pairs. Replay each pair from the same candidate exit under k-LPM/LRU, in its original chronological order. Fresh hypothetical service stamps must follow the current candidate exit. Old service timestamps can corrupt LRU. With uniform weights, compare exact integer scores m times the current cost plus the sum of pair costs. The same demand costs beyond retained capacity and all compulsory tails add common constants if the implementation scores full-block misses. The zero-pair fallback is the exact immediate incumbent. The first chronological member of each selected pair gives a one-step control with identical input pairs. This prescription is causal, and it assumes that recent cohorts carry predictive information. Same-history simulated continuations are paired comparisons and carry no independent-sampling guarantee.

**Demonstrated obstacle to a universal online dominance claim.** Under ordinary LRU with capacity two, take a warm path a/z and a cohort containing paths a/x and b/t. Serving a/x first costs three block computations and exits with b/t. Serving b/t first costs four and exits with a/x. If the next singleton requests a/x, complete costs are five and four. If it requests b/t, costs are three and six. All requests can carry a one-token compulsory tail, equal on both branches. The prefix state and visible history can be identical in both futures. The four-block choice incurs an immediate sacrifice that a tie-only policy forbids. This is a hand derivation, independent of the recorded development reversal. The fixed arrival path assumption also matters: a live conversational or tool response can influence later arrivals, whereas the replay treats their order and contents as exogenous.

**Bounded implementation correction.** Only deterministic continuation-equivalent exit states can be combined. For a common state, history and tick, each historical trial has identical future cost by induction on requests, so the least immediate-cost order represents that state exactly, retaining the incumbent on eligible ties. Leaf eviction uses depth and node ID to break equal recency stamps. A resident set alone can conflate different fates after the next insertion. As a minimal witness, caches with A older than B and B older than A both hold {A,B}. A new singleton C evicts different leaves. A following singleton A then hits only if B was older. No modification to the H=2, M=8 estimator follows from either witness.

**Empirical uncertainty.** An order can change recency without changing resident identities. Its consequences may be erased before any relevant reuse. Conversely, a past rollout can prefer an exit that harms the actual continuation or overlooks demand more than two cohorts away. Agreement with realized two-cohort k-LPM branches is a local diagnostic; episode work must be measured independently.
